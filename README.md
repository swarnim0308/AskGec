# AskGec
The aim of this project is to facilitate the students with the college queries with a chatbot giving instant responses generated using the Knowledge Base. BERT stands for Bidirectional Encoder Representation from transformations is a pretrained NLP model used to understand the queries.
It is a chatbot finetuned using pytorch and flask and Tunneled using ngrok to feed the text generated output to the cloud to get generated responses in proper human conversational context.
Web Interface is designed using HTML,CSS, JavaScript and JQuery Ajax. JQuery post request is used to retrieve data from the server to the chat interface.
